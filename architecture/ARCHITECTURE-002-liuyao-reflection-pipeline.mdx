# ARCHITECTURE-002 Liuyao Reflection Pipeline

## Outcome

Life Mirror does not ask an LLM to explain a hexagram from memory. The single deterministic Liuyao Tool computes the reading; classical and reflection knowledge are retrieved separately; Mirror Runtime assembles context; Shiguang communicates the result as compassionate reflection.

```text
User Question
  ↓
Liuyao Tool — casting, calculation, traditional analysis, evidence
  ↓
KNOWLEDGE-003 — classical text and rule meanings
  ↓
KNOWLEDGE-004 — traditional concept to human reflection mapping
  ↓
Mirror Runtime — context assembly with visible Personal Memory
  ↓
LLM — constrained language generation only
  ↓
Shiguang Persona — warm, non-predictive communication
  ↓
User
```

There is one calculation entry: `server/tools/liuyao/calculateLiuyao`. KNOWLEDGE-004 is not a second interpretation engine. It consumes computed facts and retrieved meanings; it cannot cast, select a useful god, judge strength, or invent classical meaning.

## Runtime Envelope

`assembleMirrorRuntimeContext` produces five named inputs: `userQuestion`, immutable `liuyaoTool`, `classicalKnowledge`, `reflectionKnowledge`, and `personalContext`. Missing traditional context remains `context_required`; the prompt forbids filling it.

## Response and Trace

Shiguang returns exactly six fields that render as: 拾光看到、卦象告诉我们、拾光的理解、给你的提醒、留给你的问题, plus a private-safe share line.

Every generated answer creates an audit trace:

```json
{
  "traditional_basis": "",
  "liuyao_factors": [],
  "reflection_mapping": "",
  "final_response": {}
}
```

The trace is bound into signed draft v4 and stored in `reflection_events.explanation_trace` after explicit save. The result UI can show its non-sensitive basis under “为什么拾光这样说”. Saved traces are owner-scoped at `GET /api/v1/daily-mirror/reflections/:id/explanation-trace`.

## Non-negotiable Boundaries

- Tool facts are immutable downstream.
- Knowledge explains; it does not calculate a user's reading.
- Reflection mappings are possibilities, not facts about the user.
- Memory is optional evidence and cannot turn inference into biography.
- LLM language cannot add divination conclusions.
- Timing remains a low-confidence traditional candidate, never a promise.
