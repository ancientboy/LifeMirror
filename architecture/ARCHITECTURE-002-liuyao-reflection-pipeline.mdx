# ARCHITECTURE-002 Liuyao Reflection Pipeline

## Outcome

Life Mirror does not ask an LLM to explain a hexagram from memory. The single deterministic Liuyao Tool computes the reading; classical and reflection knowledge are retrieved separately; Mirror Runtime assembles context; Shiguang communicates the result as compassionate reflection.

```text
User Question
  ↓
Topic Hint + Deterministic Intent Classifier
  ↓ only when unclear
Schema-bound LLM Intent Classifier → User Confirmation when material
  ↓
Liuyao Tool — casting, calculation, traditional analysis, evidence
  ↓
KNOWLEDGE-003 — classical text and rule meanings
  ↓
KNOWLEDGE-004 — traditional concept to human reflection mapping
  ↓
Mirror Runtime — context assembly with visible Personal Memory
  ↓
LLM — constrained language generation only
  ↓
Shiguang Persona — warm, non-predictive communication
  ↓
User
```

There is one calculation entry: `server/tools/liuyao/calculateLiuyao`. KNOWLEDGE-004 is not a second interpretation engine. It consumes computed facts and retrieved meanings; it cannot cast, select a useful god, judge strength, or invent classical meaning.

## Question Understanding Boundary

Before casting, the UI collects one broad `topicHint` and the natural-language question. `server/tools/liuyao/intent-understanding.ts` first runs deterministic classification. Clear inputs proceed without an LLM. Low-confidence, conflicting or multi-stage inputs may use the configured provider with a strict JSON Schema that contains only real-world semantics: topic, scenario, scenario focus and subject role.

The intent LLM cannot choose a useful god, line, date or result. Deterministic code maps the returned subject role to `shi`, `ying` or a six-relation target. If a distinction would change the rule family—such as interview versus offer, contact versus reconciliation, or short-term versus long-term investment—the flow stops before casting and asks the user to confirm. Invalid provider output falls back to deterministic classification; known stage ambiguity still produces deterministic confirmation options when the provider is unavailable.

The confirmed `intentSelection` is not yet a calendar context. Month branch and day pillar are resolved only after the sixth toss, using that casting timestamp. `analysisContext.intentResolution` retains source and confidence for audit but never contributes to favorable or unfavorable scoring.

## Runtime Envelope

`assembleMirrorRuntimeContext` produces five named inputs: `userQuestion`, immutable `liuyaoTool`, `classicalKnowledge`, `reflectionKnowledge`, and `personalContext`. Missing traditional context remains `context_required`; the prompt forbids filling it.

## Response and Trace

Runtime returns exactly six fields. The visible order is answer-first: `traditionalJudgment`（拾光先说）→ `reasoningExplanation`（这卦怎么看）→ `shiguangInterpretation`（拾光翻成人话）→ `practicalGuidance`（给你的建议）, plus a private-safe share line. `reflectionQuestion`（留给你的一个问题）is optional and is not part of the required completion path.

The first field must begin with “先说结论：” or the lighter “先说结果：”, then directly answer the stated question with a bounded direction: 偏向可行、有条件可行、建议暂缓, or—when complete traditional context is unavailable—仅按卦象象意. The response may not replace the question with “你真正问的是……” or defer the answer in favor of self-growth. Users can save or start another reading immediately after practical advice; reflection requires a separate optional action.

Every generated answer creates an audit trace:

```json
{
  "traditional_basis": "",
  "liuyao_factors": [],
  "reflection_mapping": "",
  "final_response": {}
}
```

The trace is bound into the current signed draft and stored in `reflection_events.explanation_trace` after explicit save. Historical draft versions remain readable. The result UI can show its non-sensitive basis under “为什么拾光这样说”. Saved traces are owner-scoped at `GET /api/v1/daily-mirror/reflections/:id/explanation-trace`.

## Non-negotiable Boundaries

- Tool facts are immutable downstream.
- Knowledge explains; it does not calculate a user's reading.
- Reflection mappings are possibilities, not facts about the user.
- Memory is optional evidence and cannot turn inference into biography.
- LLM language cannot add divination conclusions.
- Intent classification cannot choose traditional targets or contribute to verdict scoring.
- The user's desire for an answer is valid and must be satisfied before reflection.
- Shiguang may humanize a judgment but may not behave as a therapist or claim to be a fortune teller.
- Timing remains a low-confidence traditional candidate, never a promise.
