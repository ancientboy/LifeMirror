# Liuyao Reflection Pipeline Evaluation 001

These are reviewed regression fixtures, not claims about real outcomes. Each case uses fixed coin tosses and explicit traditional-analysis context so the complete pipeline is repeatable.

## Career — “这个工作机会值得接受吗？”

1. **Tool output:** 乾之坤，六爻皆动；乾宫，世六应三；官鬼第四爻为用，用神旺；日月及动爻生克已经计算；应期 remains low confidence.
2. **Knowledge retrieval:** 乾用九“见群龙无首，吉”与坤卦辞；reading rule is `six_moving_lines`.
3. **Reflection mapping:** 官鬼为用 → responsibility and external requirements; 用神旺 → existing support can be converted into action.
4. **Final Shiguang response:**
   - 拾光看到：你问的是要不要接受这份工作；真正需要看清的，也许是机会带来的成长，是否值得你承担随之而来的责任。
   - 卦象告诉我们：乾之坤既有主动开创，也提醒力量最终要落到承载与配合；官鬼为用且得时，说明责任与外部要求是这次权衡的核心线索。
   - 拾光的理解：如果职责、授权和支持条件清楚，这份机会才可能把主动性变成可持续的承担。
   - 给你的提醒：确认前三个月目标、决策权限、可调用资源，以及不愿长期承担的一项代价。
   - 留给你的问题：如果职位名称不变，但实际责任增加一倍，你仍愿意接受它吗？

## Relationship — “这段关系还有必要继续吗？”

1. **Tool output:** 坤之乾，六爻皆动；坤宫，世六应三；官鬼第三爻为用，用神囚且旬空；传统倾向不利但不等于现实结论。
2. **Knowledge retrieval:** 坤用六“利永贞”与乾卦辞；reading rule is `six_moving_lines`.
3. **Reflection mapping:** 官鬼为用 → responsibility and pressure; 用神囚 → current conditions constrain room to act.
4. **Final Shiguang response:**
   - 拾光看到：现在的坚持，究竟在维系关系，还是只在延长消耗。
   - 卦象告诉我们：坤之乾从承接转向主动；关系中的责任与现实条件目前缺少舒展空间。
   - 拾光的理解：分辨双方是否仍有共同修复的行动，而不是只有一方承载。
   - 给你的提醒：各自说清一项愿意改变的行为，并设置短期观察窗口。
   - 留给你的问题：如果对方未来三个月仍保持现在的行动方式，你愿意继续吗？

## Decision — “我现在应该创业吗？”

1. **Tool output:** 噬嗑静卦；巽宫，世五应二；世爻为用，用神休，uncertainty high.
2. **Knowledge retrieval:** 噬嗑卦辞“亨，利用狱”；no-moving-lines rule focuses on the original judgment.
3. **Reflection mapping:** 世爻为用 → the user's stance and capacity matter; 用神休 → sustainability and resource drain require attention.
4. **Final Shiguang response:**
   - 拾光看到：分清创业冲动、真实准备与可承受代价，比一个简单的是或否更重要。
   - 卦象告诉我们：噬嗑强调清障和规则，重点回到你的状态与承受力。
   - 拾光的理解：客户验证、现金期限或合伙边界中，任何含糊都不应被热情代替。
   - 给你的提醒：做四周可撤回实验，获得付费信号并写出退出条件。
   - 留给你的问题：如果四周后没有付费验证，你愿意停止、调整，还是会因已投入而继续？
