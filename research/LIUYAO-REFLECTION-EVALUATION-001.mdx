# Liuyao Reflection Pipeline Evaluation 001

These are reviewed regression fixtures, not claims about real outcomes. Each case uses fixed coin tosses and explicit traditional-analysis context so the complete pipeline is repeatable.

## Entertainment — “今天适合出去玩吗？”

1. **Tool output:** 乾之坤，六爻皆动；子孙为用，用神旺，初爻临青龙；传统倾向 favorable。
2. **Knowledge retrieval:** 乾用九与坤卦辞；reading rule is `six_moving_lines`.
3. **Reflection mapping:** 子孙为用 → 舒展、娱乐、减压；用神旺 → 当前条件较有力量。
4. **Before:** 容易把“适不适合出去”改写成人生方向或自我成长问题。
5. **After — answer-first reading:**
   - 拾光先说：先说结果：偏向可行。今天适合出去玩，更像轻松交流局，不必把行程排得太满。
   - 这卦怎么看：子孙为用且用神旺，初爻临青龙，更支持放松、娱乐与交流；六爻皆动提示节奏容易变化。
   - 拾光翻成人话：可以去，而且大概率玩得开；少一点必须完成的项目，随性一点反而更舒服。
   - 给你的建议：朋友聚会或短途活动可以去，少排一个耗体力环节，给返程留出余量。
   - 可选问题：你今天更想要热闹，还是更想真正放松一下？

## Career — “这个工作机会值得接受吗？”

1. **Tool output:** 乾之坤，六爻皆动；乾宫，世六应三；官鬼第四爻为用，用神旺；日月及动爻生克已经计算；应期 remains low confidence.
2. **Knowledge retrieval:** 乾用九“见群龙无首，吉”与坤卦辞；reading rule is `six_moving_lines`.
3. **Reflection mapping:** 官鬼为用 → responsibility and external requirements; 用神旺 → existing support can be converted into action.
4. **Before:** “真正需要看清的，也许是……”在回答前改写用户问题，过早进入成长反思。
5. **After — answer-first reading:**
   - 拾光先说：先说结论：偏向可行。这个工作机会可以接受，但前提是职责、权限和支持资源能够匹配。
   - 判断依据：乾之坤有主动开创后转入承载之象；官鬼为用且用神旺，责任、职位与外部要求是核心，当前条件有一定承接力。
   - 拾光翻成人话：这份机会值得认真接住，但真正决定它能否长久的，是授权与支持能否匹配责任。
   - 给你的建议：确认前三个月目标、决策权限、可调用资源，以及不愿长期承担的一项代价。
   - 留给你的问题：如果职位名称不变，但实际责任增加一倍，你仍愿意接受它吗？

## Relationship — “这段关系还有必要继续吗？”

1. **Tool output:** 坤之乾，六爻皆动；坤宫，世六应三；官鬼第三爻为用，用神囚且旬空；传统倾向不利但不等于现实结论。
2. **Knowledge retrieval:** 坤用六“利永贞”与乾卦辞；reading rule is `six_moving_lines`.
3. **Reflection mapping:** 官鬼为用 → responsibility and pressure; 用神囚 → current conditions constrain room to act.
4. **Before:** 一上来追问“是在维系还是延长消耗”，没有回答还要不要继续。
5. **After — answer-first reading:**
   - 拾光先说：先说结论：建议暂缓继续投入。当前修复条件偏弱，继续需要对方出现明确行动。
   - 判断依据：官鬼为用，但用神囚且旬空，关系所依赖的现实条件受限，不宜只凭期待追加投入。
   - 拾光翻成人话：不必被催促立刻结束，但应先看双方有没有共同修复的行动，再决定是否继续承载。
   - 给你的建议：各自说清一项愿意改变的行为，并设置短期观察窗口。
   - 留给你的问题：如果对方未来三个月仍保持现在的行动方式，你愿意继续吗？

## Decision — “我现在应该创业吗？”

1. **Tool output:** 噬嗑静卦；巽宫，世五应二；世爻为用，用神休，uncertainty high.
2. **Knowledge retrieval:** 噬嗑卦辞“亨，利用狱”；no-moving-lines rule focuses on the original judgment.
3. **Reflection mapping:** 世爻为用 → the user's stance and capacity matter; 用神休 → sustainability and resource drain require attention.
4. **Before:** 用“比一个简单的是或否更重要”回避用户要不要创业的直接问题。
5. **After — answer-first reading:**
   - 拾光先说：先说结论：有条件可行。可以开始创业验证，但不适合立刻重投入或彻底押上全部。
   - 判断依据：噬嗑静卦强调清障与规则；世爻为用而用神休，资源消耗与个人承受力是主要限制。
   - 拾光翻成人话：创业念头可以被认真对待，但应从可撤回的小实验开始，让客户、现金期限和合伙边界接受现实检验。
   - 给你的建议：做四周可撤回实验，获得付费信号并写出退出条件。
   - 留给你的问题：如果四周后没有付费验证，你愿意停止、调整，还是会因已投入而继续？

Automated coverage lives in `server/reflection/pipeline-evaluation.test.ts` and verifies Tool completion, knowledge retrieval, mapping provenance, answer-first language, response schema and explanation trace for all three cases. In every case, reflection remains the final step and may not invalidate the judgment.
