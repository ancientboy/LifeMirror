# DESIGN-004 Mirror Reflection Interface Design

## 镜像反思界面设计规范

## Abstract

Mirror Reflection is the core AI experience layer of Life Mirror. It connects symbolic knowledge, personal context, memory and AI reasoning into a personal reflection experience.

The goal is not to provide deterministic answers, but to help users understand themselves through structured reflection.

## Reflection Architecture

```text
Observation
↓
Meaning
↓
Personal Connection
↓
Reflection Question
↓
Next Action
```

## Core Components

### Reflection Card

A unified container for AI-generated insights.

### Insight Highlight

Highlights important patterns discovered from the user's mirror.

### Question Prompt

Encourages deeper self exploration.

## Trust Design

The interface should explain the sources behind reflection:

- Symbolic interpretation
- Personal memory
- Previous patterns

## Memory Connection

Reflection results can become part of Personal Mirror Memory and contribute to future pattern understanding.

## Design Principle

Sixyao provides symbols.

AI provides interpretation.

Personal experience creates meaning.
