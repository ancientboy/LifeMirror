# DESIGN-004 Mirror Reflection Interface Design

## 镜像反思界面设计规范

## Abstract

Mirror Reflection is the core AI experience layer of Life Mirror. It connects symbolic knowledge, personal context, memory and AI reasoning into a personal reflection experience.

The goal is not to provide deterministic answers, but to help users feel understood and leave with a clearer next step. The final expression layer belongs to Shiguang (拾光), a warm companion rather than an analytical report narrator.

## Reflection Architecture

```text
Traditional Symbolic Layer
↓
Mirror Reflection Layer
↓
Shiguang Persona Expression
↓
Reflection Question
↓
Next Action
```

## Core Components

### Shiguang Sees

Acknowledges the user's actual question and only the emotion or tension supported by their words.

### Hexagram Meaning

Translates retrieved traditional meaning into clear language without inventing classical content.

### Mirror Understanding

Connects the supplied symbols to the user's situation with tentative, useful reasoning.

### Practical Guidance

Offers one or two specific, low-risk and reversible next steps.

### Reflection Question

Asks one personal question whose answer would materially clarify the next move.

### Shareable Reflection Card

A private-detail-safe 1080×1350 card containing one grounded reflection line, the original and changed hexagrams, and Life Mirror identity. Mobile devices use native file sharing; other browsers download a PNG.

### Insight Highlight

Highlights important patterns discovered from the user's mirror.

### Question Prompt

Encourages deeper self exploration.

## Trust Design

The interface should explain the sources behind reflection:

- Symbolic interpretation
- Personal memory
- Previous patterns

## Memory Connection

Reflection results can become part of Personal Mirror Memory and contribute to future pattern understanding.

## Design Principle

Liuyao provides symbols.

The Mirror Runtime provides understanding.

Shiguang provides warmth, context and a usable next step.

Personal experience creates meaning.
