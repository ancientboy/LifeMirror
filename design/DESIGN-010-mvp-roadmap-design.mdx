# DESIGN-010

# MVP Roadmap Design

## Life Mirror 第一阶段产品路线设计

**Life Mirror Product Design Paper**

Version 1.0 · August 2026

---

# Abstract

Life Mirror MVP 的目标不是一次完成完整人生镜像系统，而是验证核心价值：

> 用户是否愿意通过持续反思，让 AI 逐渐理解自己。

第一阶段围绕 Daily Mirror 建立最小闭环：

Question → Reflection → Memory → Pattern

---

# 1. MVP Strategy

MVP 不追求功能数量，而验证三个核心问题：

1. 用户是否愿意主动探索自己。
2. AI Reflection 是否产生价值感。
3. 用户是否愿意持续积累个人镜像。

---

# 2. MVP Scope

## Core Experience

Daily Mirror

包含：

- 用户问题输入
- 六爻 Symbolic Experience
- Traditional Interpretation
- AI Mirror Reflection
- Memory 保存

---

# 3. Platform Strategy

第一阶段：

H5 + 微信小程序。

原因：

- 降低使用门槛
- 方便传播
- 适合兴趣入口增长

后续：

Web App → Native App
