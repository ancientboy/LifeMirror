# DESIGN-008 Growth Loop & Retention Design

## Abstract

Life Mirror's value comes from long-term understanding, not one-time answers.

The growth system connects:

Interest → Reflection → Memory → Pattern → Understanding → Return.

## 1. Growth Philosophy

Traditional tools optimize single consumption.

Life Mirror builds a continuous personal understanding loop.

## 2. Core Growth Loop

```
Entry
 ↓
Reflection
 ↓
Memory
 ↓
Pattern Discovery
 ↓
New Exploration
```

## 3. Acquisition Loop

Entry points:

- Liuyao
- Astrology
- Personality Exploration
- Symbolic Reflection

The goal is first connection, not immediate conversion.

## 4. Activation Loop

First successful experience:

Question → Reflection → Save Mirror

Creates the user's first personal mirror record.

## 5. Retention Loop

The shipped return loop is:

```text
Open
  → Today's Shiguang
  → Follow up the last unfinished event
  → One-tap mood response
  → Conversation
  → Explicit save
  → Initial / updated Mirror DNA
```

The home experience must not ask users to reorganize their entire story. A useful opening references one recent, user-owned event and offers a low-effort response.

## 6. Pattern Discovery

The system identifies meaningful long-term themes from accumulated reflections.

Examples:

- Career transition patterns
- Relationship themes
- Growth directions

The first saved event creates an initial observation so the first experience is not empty. A repeated Pattern still requires at least two independent signals. The UI must distinguish initial observation, repeated pattern and high-confidence long-term tendency.

## 7. Sharing and Relationship Loop

Sharing has three different jobs:

- self card: “this describes me”;
- relationship card: “I want one person to respond”;
- compare card: “create yours and compare with me”.

The link must support response, identity confirmation and a private relationship request. A saved image alone is not a growth loop.

## 8. Active interaction boundary

In-product active interaction is shipped through Today's Shiguang and last-event follow-up. External email or push delivery remains planned and must be opt-in, rate-limited and quiet by default. Avoid generic daily fortune spam.

## 9. Premium Conversion

Premium value comes from deeper understanding:

- Unlimited Reflection
- Deep Analysis
- Career Mirror
- Relationship Mirror
- Life Review

## Conclusion

Life Mirror grows through a long-term relationship between users and their own evolving mirror.
