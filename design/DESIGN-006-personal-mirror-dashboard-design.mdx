# DESIGN-006 Personal Mirror Dashboard Design

## 个人镜像主页设计规范

Version 1.0 · August 2026

## Abstract

Personal Mirror Dashboard is the long-term home of Life Mirror. It is not a traditional analytics dashboard, but a personal understanding space where users observe their evolving mirror.

## Design Goal

The experience should feel like:

> This is my mirror.

Not:

> This is an AI tool console.

## Information Architecture

```text
Personal Mirror

├── Current Reflection
├── Mirror DNA
├── Recent Patterns
├── Timeline
└── Explore
```

## Core Components

### Current Reflection

Shows the latest insight generated from recent reflections.

### Mirror DNA

Displays evolving personal patterns, not fixed personality labels.

### Pattern Discovery

Shows long-term observations discovered from memories and reflections.

### Timeline Preview

Displays important Mirror Moments.

## Privacy Design

Users control:

- Data sources
- Corrections
- Deletion
- Visibility

## Future Evolution

Dashboard evolves into the personal AI operating space containing goals, decisions, and growth plans.
