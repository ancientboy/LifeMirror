# DESIGN-005

# Memory & Mirror Timeline Design

## 记忆与镜像成长时间线设计规范

## Abstract

Memory Timeline is the long-term value layer of Life Mirror. It transforms individual questions, reflections and experiences into an evolving personal understanding map.

## Design Goal

Traditional history records events.

Life Mirror records:

```
Event
↓
Meaning
↓
Pattern
↓
Growth
```

## Timeline Architecture

```
Memory Timeline

├── Events
├── Reflections
├── Patterns
└── Growth
```

## Mirror Moment

Each meaningful interaction becomes a Mirror Moment.

Contains:

- date
- topic
- trigger
- reflection
- pattern signal

## Pattern Evolution

Repeated reflections gradually form higher-level patterns.

Example:

Single event:

"Thinking about entrepreneurship"

Multiple signals:

"Repeated exploration of creation and independence"

Evolution:

Mirror DNA update.

## User Control

Users can:

- edit
- delete
- hide
- correct

Memory belongs to the user.

## Visual Language

Timeline should feel like a personal constellation rather than a simple list.

Elements:

- nodes
- connections
- phases
- evolution paths

## Conclusion

Memory Timeline turns individual moments into a continuously evolving personal mirror.
