# DESIGN-002

# Daily Mirror Interface Specification

## 每日镜像界面设计规范

**Life Mirror Product Design Paper**

---

## Abstract

Daily Mirror 是 Life Mirror 第一个用户体验入口。

通过每日一次低门槛互动，让用户从象征探索进入个人 AI 镜像关系。

核心流程：

Question → Symbolic Exploration → Reflection → Memory → Pattern

---

# 1. Experience Goal

用户在 5 分钟内完成：

- 提出问题
- 完成六爻体验
- 查看传统解释
- 获得 AI Reflection
- 保存第一次镜像

目标不是预测，而是帮助用户建立自我理解。

---

# 2. Information Architecture

```text
Daily Mirror

├── Home
├── Question
├── Divination
├── Reveal
├── Reflection
├── Save
└── History
```

---

# 3. Core Experience

## Home

展示：

今日镜像

邀请用户提出正在思考的问题。

---

## Question

支持自然语言问题：

- 职业方向
- 关系变化
- 人生选择
- 成长困惑

---

## Divination

六次铜钱起卦交互：

第一次摇卦 → 初爻

直到第六次 → 上爻

形成完整卦象。

---

# 4. Result Experience

结果分为三层：

## Traditional Interpretation

展示：

- 本卦
- 动爻
- 变卦
- 传统象征意义


## Mirror Reflection

AI 结合：

- 用户问题
- Personal Context
- Mirror Memory

生成现代反思。


## Save To Mirror

保存：

- 问题
- 卦象
- Reflection
- 时间

进入个人镜像。

---

# 5. History

历史不是算卦记录。

而是人生探索轨迹。

---

# 6. Sharing

分享内容强调反思，不展示确定性预测。

---

# 7. Mobile First

优先支持：

- H5
- 微信小程序

设计目标：

低输入、单手操作、强视觉反馈。

---

# Conclusion

Daily Mirror 是从兴趣入口进入 Personal AI Mirror 的第一条路径。

一个问题开启探索，一次反思建立镜像。
