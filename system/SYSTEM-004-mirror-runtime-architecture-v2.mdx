# SYSTEM-004 Mirror Runtime Architecture

## Personal AI Runtime

Life Mirror 采用 Runtime 架构，而不是多个孤立 Agent。

## Core Modules

- Context Manager
- State Manager
- Memory Manager
- Tool Router
- Reasoning Engine
- Reflection Engine
- Learning Runtime

## Runtime Flow

```
User
↓
Context Assembly
↓
Memory + Tools
↓
LLM Reasoning
↓
Reflection
↓
Memory Evolution
```

## Runtime Principles

### One Runtime, Many Capabilities

多个能力共享同一个人生理解系统。

### Context Before Response

先理解上下文，再生成反馈。

### Reflection Before Action

先理解人生，再支持行动。
