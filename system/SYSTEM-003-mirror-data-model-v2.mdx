# SYSTEM-003 Mirror Data Model

## 人生镜像数据模型

## Purpose

定义 Life Mirror 如何将人生信号组织为动态个人模型。

## Core Entities

- Identity
- Context
- Life Event
- Decision
- Memory
- Emotion
- Value
- Behavior
- Relationship
- Goal
- Growth

## Memory Evolution

```
Raw Interaction
↓
Signal Memory
↓
Structured Memory
↓
Pattern Memory
↓
Mirror DNA
```

## Graph Relationship

人生信息通过关系连接形成 Mirror Graph：

- caused_by
- influenced
- connected_to
- changed_into

## Confidence Model

单次信号不会直接改变人格模型。

需要通过长期证据形成稳定模式。

## Principle

Life Mirror 保存的不只是发生了什么，而是理解为什么重要。
