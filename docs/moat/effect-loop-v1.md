# LifeMirror 护城河设计 · 效果闭环 v1

> 状态:v1 草案(2026-08-09)
> 决策人:ZhiLie
> 定位前提:LifeMirror = **关系 AI**(帮用户更好地经营真实关系);玄学/命理 = 吸引用户的兴趣入口(获客皮),不是内核。
> 护城河主轴:**效果闭环**——别的玩法都能被抄,唯独"你和你身边每个人、逐次校准的真实互动历史"抄不走。

---

## 0. 一句话定义

LifeMirror 的护城河,是一条**闭合的、越转越懂你的回路**:
用户在 LifeMirror 里**演练**一段真实关系里的沟通 → 到**现实里用**出来 → **回来复盘**结果 → 系统据此**更懂用户和他关系网里的每一个人**,下一次演练更准。

护城河不在"演练"这一步(那是玩具,可抄),而在**"回来复盘 + 逐次沉淀独家关系数据"**这两步。

---

## 1. 回路四步

```
①演练  →  ②现实使用  →  ③回收结果  →  ④学习/变得更懂
  ↑                                              │
  └──────────────────────────────────────────────┘
```

| 步骤 | 用户动作 | 系统动作 | 这一步的护城河价值 |
|---|---|---|---|
| ① 演练 | 输入要沟通的对象(暧昧对象/老板/同事/家人)+ 其生日、性格等建"基础盘",模拟对话演练 | 生成对手镜像、给演练反馈 | 低(可抄) |
| ② 现实使用 | 带着演练结果,去现实里真的开口 | 结尾埋"未完成钩子",把用户推向现实 | 低,但是闭环的必经桥 |
| ③ 回收结果 | 极轻地报告现实里发生了什么(顺利/一般/翻车 + 一句话) | 主动回访、超轻表单回收 | **高(闭环焊点,99% 产品在此漏光)** |
| ④ 学习 | 看见系统更懂自己和对方 | 更新该关系对象的镜像档案、展示成长曲线 | **最高(独家数据在此沉淀)** |

**核心工程难题:** 效果闭环的敌人是"摩擦"。每加一步复盘就掉一批用户。目标 = 让"回来复盘"几乎零摩擦,却又能沉淀出独家数据。做成 = 护城河成立;做不成 = 又一个陪聊。

---

## 2. 前三件事(要先做实闭环,只做这三件)

### 第一件:把"回来复盘"设计成产品的心跳,不是可选项
这是生死线。用户练完就走 = 没有闭环,只有演练玩具。
- **演练结尾不给"完成感",给"未完成的钩子"**:不是"演练完成 ✓",而是"去跟他说,回来告诉我他什么反应"——留一个 open loop,让用户带着任务离开。
- **主动回访**:演练后 1–3 天,拾光主动推:"上次跟暧昧对象那段,聊了吗?咋样?"(顺带强化"它记得我"的记忆卖点)。
- **复盘要极轻**:一句话,或三个表情(顺利 / 一般 / 翻车)即可回收。让用户写小作文 = 回路必漏。

### 第二件:让每次真实结果,可见地改变系统对"他和这个人"的理解
独家数据护城河,只有在用户**看得见系统变聪明**时才形成。
- 每个关系对象建一个**关系镜像档案**,随每次复盘更新:"上次你担心他冷淡 → 实际他其实在意 → 更新对他的判断"。
- **展示成长曲线**:"3 周前你跟老板说话会绕,现在你能直接提需求了。" 把"效果"变成用户摸得到、且专属于他的东西。
- 沉淀点:别人抄得走玩法,抄不走"你和你老板 12 次真实互动的历史"。

### 第三件:先给"效果"一个可测的定义,否则闭环是空壳
- 早期押一个指标:**行动发生率**——因为赛道是"低压力社交 / 不敢开口",**"用户真的去现实里开口了"本身就是价值**,不用等关系改善那么远。
- 后续可加:关系改善自评(主观)、回来率(行为)。

---

## 3. 北极星指标

> **闭环完成率 = 回收到真实结果的演练数 ÷ 发起的演练数**

- **不是** DAU、不是演练次数、不是注册量。
- 早期唯一该盯的数字。它同时体现:钩子有没有把人推向现实、回访有没有把人拉回来、复盘摩擦够不够低。
- 辅助指标:行动发生率(演练→现实开口的比例)、二次演练率(同一关系对象被再次演练)。

---

## 4. 两周最小验证(先别写代码也能测)

**目标:验证闭环到底漏不漏。** 可以用最土的方式跑(人工 / 半人工 / 微信群都行)。

**方法:**
1. 找 **10–20 个真实用户**(优先社交焦虑 / 不敢开口人群)。
2. 每人做 1 次真实的关系演练(暧昧对象 / 老板 / 家人任选)。
3. 演练后 1–3 天,主动问一次:**"你真的去现实里用了吗?结果怎样?"**
4. 只测一个数:**演练后,多少人真的去现实里用了、并回来告诉你结果?**

**判读:**
- **< 20%** → 回路是漏的。别的先全都别管,专心堵"回收结果"这一步(第一件事)。
- **20%–40%** → 有信号,优化钩子与回访话术、降低复盘摩擦。
- **> 40%** → 你摸到了别人没有的东西,可以开始把闭环产品化、加码第二件事(独家数据沉淀)。

---

## 5. 三条护城河 = 一条飞轮链(不是三选一)

最重要的判断:效果闭环、独家关系数据、信任品牌**不是三块独立的地,是同一条飞轮的三段**。你不用"选另外两条",把第 1 条做实,第 2、3 条会自己长出来。

```
1 效果闭环(引擎)  →  2 独家关系数据(存钱罐)  →  3 信任品牌(终局武器)
        ↑_________________________________________________________│
```

### 2 独家关系数据 —— 闭环的沉淀物,不是独立的河
- **本质**:闭环每转一圈,就沉淀一层"用户 + 他身边每个人"的逐次校准画像。它是护城河 1 的**存钱罐**。
- **为什么硬**:真正的数据网络效应——用得越久越厚,迁移成本越高;这才是"记忆护城河"这次真正成立的地方(因为它绑的是**真实结果**,不是凭空存储)。而且是**双向关系图谱**:不只懂用户,还懂用户的老板/暧昧对象。
- **三个雷**:
  1. **隐私/伦理**:对真实第三人建模、未经其同意——数据护城河最大的法务与信任风险,越做越大。
  2. **厚 ≠ 有用**:若闭环漏(第 1 条没做实),沉淀的是死数据/噪音。**没有 1,2 根本不存在。**
  3. **冷启动**:新用户数据薄,2 对他不成立(回到 Day1 问题)。
- **结论**:别单独投资它。投 1,数据自动来。

### 3 信任品牌 —— 对抗大厂的唯一非对称武器
- **本质**:在一个"AI 陪伴越用越孤独"的赛道里,做那个**真的帮你走回现实**的牌子。
- **为什么它可能是终局护城河**:2(数据)大厂能用更多数据超越;但"这个 AI 真诚待我、不让我上瘾、把我推回现实"的情感信任,**微信/字节做不出来**——它们的商业模式要你**留在 App 里**,与"把你推回现实"**天生冲突**。这是大厂抄不走的东西。
- **两个雷**:
  1. **极脆**:一次伤害(AI 给坏建议害你现实翻车 / 被发现偷偷建档)就崩,且**不可逆**。
  2. **极慢**:滞后指标,只能靠长期兑现效果攒,买不来;且与增长/变现天生张力(要信任就得克制)——碰回定位悖论。

### 战略排序
- **现在 100% 压第 1 条(效果闭环)**,因为它同时是 2 的来源、3 的前提。
- 做 1 的同时,埋两个"为 2、3 服务的今日决定":
  - **为 2**:从第一天就**结构化存关系镜像数据**(字段设计好,别等以后补——补不回来)。
  - **为 3**:从第一天就把 **"不诱导上瘾、把用户推回现实" 立为产品铁律**。信任是滞后的——**今天每一个克制的决定,都是三年后品牌的本金。**

### ⚠️ 一个待 ZhiLie 决断的核心张力
"把用户推回现实"的铁律(为护城河 3),与"先给娱乐性、后期慢慢引导"的增长打法(为获客),**是打架的**:前者要克制时长与上瘾,后者靠时长与爽感拉新。
> 待决:早期到底偏哪边?何时、以什么信号从"娱乐拉新"切换到"推回现实"?这条切换曲线没想清楚,护城河 3 就是句口号。

## 6. 下一步 / 待办

- 关系对象镜像档案的**数据结构**(字段、更新规则、版本化)——直接服务护城河 2,优先级高。
- 复盘回收的具体**交互**(推送时机、话术、超轻表单形态)——直接决定北极星"闭环完成率"。
- **伦理/隐私**:对真实第三人(老板/暧昧对象)建模的边界与告知方式。
- 第 5 节那条"娱乐拉新 ↔ 推回现实"的**切换曲线**,需要一个明确的判断信号。
