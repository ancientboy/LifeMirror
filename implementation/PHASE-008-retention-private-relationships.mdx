# 留存、主动陪伴与私密关系

## Product thesis

LifeMirror 的留存不是靠每日重新算一次，而是靠拾光记得用户正在经历什么，并在合适时机把未完成的事情温柔地接回来。

核心循环：

```text
今日拾光 → 继续对话 → 保存线索 → Mirror DNA 更新 → 关系分享／回应 → 再次对话
```

## Shipped in 0.8.0

- 每次打开首页显示日期化的“今日拾光”。
- 读取最近一次已保存镜像，显示上次在意的事并询问后续。
- 紧绷、犹豫、期待、疲惫四个低门槛回应直接进入对话。
- 第一次保存即形成明确标注的初始 Mirror DNA；第二条独立同主题证据后才升级为重复模式。
- 登录用户获得唯一 `LM-XXXXXXXX` LifeMirror ID。
- 按 ID 搜索、确认身份、发送／接受／移除好友申请。
- 邀请链接支持系统分享、复制回退和明确状态反馈。
- 双方授权出生资料后生成私密关系镜像；不暴露具体出生时间、地点与坐标。
- 分享卡链接允许对方回应，并承接到关系申请。

## Memory rules

- 命盘与占星使用同一份出生资料；完成后无需重复创建，只有资料错误或发生更正时才重算。
- 本命结构保持稳定；后续变化应来自行运／流年、现实事件与用户反馈，而不是随机重复生成本命结果。
- 常规聊天仅在用户开启记忆后检索相关的明确事实和已保存镜像；不把全部对话自动永久化。
- 单次记录可产生“初始观察”，但不能伪装成稳定人格模式。
- 新证据可以支持、修正或推翻旧观察；所有模式都必须保留用户控制。

## Next delivery slice

1. 站外触达：用户可选的邮件／推送，每日或事件后续提醒，带冷却与免打扰。
2. 通知中心：好友申请、分享回应、关系镜像更新，所有通知可单独关闭。
3. 关系模型：从太阳星座元素摘要升级到双方完整授权资料与共同事件证据。
4. 安全运营：举报、屏蔽记录、滥用限流、删除账户与社交数据导出。
5. 留存评估：首日完成率、首次保存率、D1/D7 回访、后续回应率、关系邀请转化率。

公开动态广场不属于当前优先级。第一阶段保持“私密关系”，避免产品退化为普通占星社区。
