# 专业级命盘、塔罗与占星验收清单

“专业”指计算可复现、来源可追溯、解释有边界，并不代表科学预测或确定性断言。出生资料表单与入口属于本阶段的 UI 基础，不能被计为推演引擎完成。

## 共同基础（P0）

- [x] 统一出生资料：年、月、日、时间、未知时间、地点与时区提示。
- [x] 年份可直接输入、候选列表滚动，并提供年代快捷入口；移动端不依赖难用的原生日期轮盘。
- [ ] 城市检索、经纬度、IANA 时区与夏令时历史解析。
- [ ] 计算结果、解释文本、证据来源、置信度与限制分层存储。
- [ ] 输入修正、版本追踪、导出、删除与隐私同意。
- [ ] 金标准案例、跨时区边界案例、回归测试和人工专家复核。

## 命盘 / 四柱（东方）

- [x] 确定性四柱核心 v0.1：立春换年、十二节换月、午夜/子初换日策略可配置，并在结果中展示相邻节气和计算口径。
- [x] 支持经度 + 时区中央经线 + 均时差的真太阳时校正；未知时辰时不生成时柱、时柱藏干或时柱十神。
- [x] 四柱、藏干、十神、五行、纳音已接入可复算引擎；刑冲合害与旺衰仍待实现并经流派复核。
- [ ] 起运顺逆、起运岁数、大运、流年、流月计算及依据展开。
- [ ] 区分流派差异，不把用神、格局等争议判断伪装成唯一答案。
- [ ] 输出结构：原始盘面 → 计算依据 → 多种解释候选 → 现实反思问题。

## 塔罗（西方）

- [x] 三张牌体验与问题聚焦流程。
- [x] 完整 78 张牌、正逆位、牌阵位置语义和加密随机抽牌。
- [x] 牌义知识库区分大/小阿尔卡那、四元素、数字与宫廷牌结构；传统出处书目仍待补齐。
- [x] 三张牌解读综合“问题语境 × 牌位 × 单牌 × 牌间关系”，并展示重复元素、大牌密度与逆位反向信号。
- [x] 支持单牌、三张时间线、关系镜像与五牌决策澄清牌阵；所有牌位均强调验证，不提供必然结果或恐吓性断语。
- [x] 抽牌记录可在用户明确操作后保存到当前设备，并清楚说明不会自动上传；账号级同步、导出与删除入口仍待统一记忆 API 接入。
- [ ] 为 78 张牌补齐逐条传统出处与版本信息；当前已展示盘面事实、牌义依据、反向信号与可执行反思。

## 占星（西方）

- [ ] 明确黄道体系、地心模型、宫制与使用的星历版本。
- [ ] 行星、轴点、宫头、主要相位与容许度的确定性计算。
- [ ] 历史时区/夏令时处理；出生时间未知时隐藏上升点和宫位结论。
- [ ] 本命盘 SVG/Canvas 可视化，支持盘面层级开关与无障碍文本表。
- [ ] 解读层次：天体 → 星座 → 宫位 → 相位 → 结构主题，标注相互增强或矛盾。
- [ ] 推运/行运单独分期实现，并与本命描述明确区分。

## 拾光体验与安全

- [x] 东方、西方对话分别使用同一角色的 Q 版双皮肤头像。
- [x] 六爻、命盘与塔罗结果页支持继续追问，并以逐段流式呈现回复；未登录时明确标记为设备内即时陪伴模式。
- [x] 六爻、命盘与塔罗均提供“一句话镜像”分享卡片。
- [ ] 占星在确定性星盘引擎完成后生成基于真实盘面的“一句话镜像”，不得使用无盘面依据的占位结论。
- [ ] 个人镜像服务器接入：部署认证会话、生产数据库与同源 API，完成跨设备记录、对话上下文和记忆授权；断线时继续保留本机降级能力。
- [ ] 服务端对话流：接入已配置的 Reflection Provider，以 SSE/流式响应返回；失败时降级为设备内反思提示且不伪装为 AI 回答。
- [ ] 每条长解读提供“盘面事实 / 象征解释 / 拾光反思”标签。
- [ ] 健康、法律、财务、生死等高风险问题触发安全边界与专业求助提示。
- [ ] 用户可以评价准确性、标记不适用，并让反馈进入评估而非直接改写事实。

## 发布闸门

任何系统只有在确定性计算、来源、边界测试、端到端测试和专家抽检全部通过后，才可从“体验版”标记为“专业版”。

### 命盘 v0.1 实现边界

- 历法核心固定使用 `lunar-javascript 1.7.7`，支持 1900–2100；版本写入每次结果，避免依赖升级后静默改变旧盘。
- 出生时间以出生地当时的民用钟表时间输入；当前由用户明确选择当日 UTC 偏移，城市到 IANA 时区及历史夏令时的自动解析仍未完成。
- 真太阳时使用经度修正与均时差近似；节气、子时或时辰边界附近必须进入金标准案例和专家复核，不能仅凭界面结果宣称专业版完成。
