# 专业级命盘、塔罗与占星验收清单

“专业”指计算可复现、来源可追溯、解释有边界，并不代表科学预测或确定性断言。出生资料表单与入口属于本阶段的 UI 基础，不能被计为推演引擎完成。

## 共同基础（P0）

- [x] 统一出生资料：年、月、日、时间、未知时间、地点与时区提示。
- [x] 年份可直接输入、候选列表滚动，并提供年代快捷入口；移动端不依赖难用的原生日期轮盘。
- [ ] 城市检索、经纬度、IANA 时区与夏令时历史解析。
- [ ] 计算结果、解释文本、证据来源、置信度与限制分层存储。
- [ ] 输入修正、版本追踪、导出、删除与隐私同意。
- [ ] 金标准案例、跨时区边界案例、回归测试和人工专家复核。

## 命盘 / 四柱（东方）

- [ ] 节气换月、立春换年、子初换日策略可配置并明确展示。
- [ ] 真太阳时校正；未知时辰时禁止生成时柱相关结论。
- [ ] 四柱、藏干、十神、五行、纳音、刑冲合害与旺衰的确定性计算。
- [ ] 起运顺逆、起运岁数、大运、流年、流月计算及依据展开。
- [ ] 区分流派差异，不把用神、格局等争议判断伪装成唯一答案。
- [ ] 输出结构：原始盘面 → 计算依据 → 多种解释候选 → 现实反思问题。

## 塔罗（西方）

- [x] 三张牌体验与问题聚焦流程。
- [ ] 完整 78 张牌、正逆位、牌阵位置语义和加密随机抽牌。
- [ ] 牌义知识库需区分大/小阿尔卡那、元素、数字、宫廷牌与象征出处。
- [ ] 解读应综合“问题语境 × 牌位 × 单牌 × 牌间关系”，避免拼接固定文案。
- [ ] 支持单牌、三张牌、关系牌阵与决策澄清牌阵；不提供必然结果或恐吓性断语。
- [ ] 展示抽牌记录、牌义证据、替代解读、反向信号与可执行反思。

## 占星（西方）

- [ ] 明确黄道体系、地心模型、宫制与使用的星历版本。
- [ ] 行星、轴点、宫头、主要相位与容许度的确定性计算。
- [ ] 历史时区/夏令时处理；出生时间未知时隐藏上升点和宫位结论。
- [ ] 本命盘 SVG/Canvas 可视化，支持盘面层级开关与无障碍文本表。
- [ ] 解读层次：天体 → 星座 → 宫位 → 相位 → 结构主题，标注相互增强或矛盾。
- [ ] 推运/行运单独分期实现，并与本命描述明确区分。

## 拾光体验与安全

- [x] 东方、西方对话分别使用同一角色的 Q 版双皮肤头像。
- [ ] 每条长解读提供“盘面事实 / 象征解释 / 拾光反思”标签。
- [ ] 健康、法律、财务、生死等高风险问题触发安全边界与专业求助提示。
- [ ] 用户可以评价准确性、标记不适用，并让反馈进入评估而非直接改写事实。

## 发布闸门

任何系统只有在确定性计算、来源、边界测试、端到端测试和专家抽检全部通过后，才可从“体验版”标记为“专业版”。
