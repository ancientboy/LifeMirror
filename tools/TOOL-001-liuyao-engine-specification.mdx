# TOOL-001

# Liuyao Engine Specification

## 六爻计算引擎规范

**Life Mirror Institute · Tool Architecture Paper**

---

## Abstract

Life Mirror 将六爻作为 Symbolic Knowledge Framework 的第一个应用案例。

六爻计算过程不由 LLM 生成，而由独立计算工具执行，保证计算结果可验证、可追踪。

Liuyao Engine 负责：

- 起卦
- 六爻生成
- 阴阳转换
- 动爻识别
- 本卦生成
- 变卦生成
- 结构化输出

随后由 Knowledge Retrieval、Mirror Runtime 和 Reflection Engine 完成现代化个人解释。

# 2. Design Principles

## Deterministic Calculation

六爻计算必须：

- 可重复
- 可验证
- 可追踪

不能由 LLM 自由生成卦象。

## Separation of Calculation and Interpretation

工具负责计算。

知识系统负责传统解释。

AI 负责个人化反思。

---

# 3. Divination Method

第一版本采用：

## Three Coins Method

三枚铜钱起卦。

一次完整起卦需要六次摇卦：

```text
第一次 → 初爻
第二次 → 二爻
第三次 → 三爻
第四次 → 四爻
第五次 → 五爻
第六次 → 上爻
```

六个爻组成完整卦象。
