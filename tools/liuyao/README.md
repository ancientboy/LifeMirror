# Liuyao Engine · 六爻规则引擎

Life Mirror `tools/` 下的**确定性六爻排盘断卦引擎**。零随机、零 LLM、可回归测试。

把六爻「装卦 → 断卦」翻译成可执行、可测试、会自报置信度的规则代码。LLM(拾光)只负责把引擎产出的「断语要点」润色成陪伴式表达,**不参与任何命理演算** —— 因此不会因模型换代或幻觉而断错卦。

## 用法

    from liuyao import full_reading
    fr = full_reading(
        lines_raw=[6,7,7,7,8,8],   # 摇卦 6 次(初->上):6 老阴 / 7 少阳 / 8 少阴 / 9 老阳
        category="事业",            # 所测之事(见 analysis.CATEGORY_YONGSHEN)
        month="未",                # 月建地支(节气月,由历法层提供)
        day=("戊","申"),           # 日辰干支
    )

返回 §3.2.1 契约:`卦象事实` + `用神分析` + `断语要点(依据 + 置信)` + `整体倾向` + `不确定度` + `应期` + `元数据`。

## 装卦(engine.py)

- **八经卦 = 二进制**:每卦 3 位 0/1(阴/阳,下->上);六爻卦 = 6 位。翻爻、拆上下卦皆位运算。
- **定卦宫 + 世应**:由京房八宫「卦变规则」从 8 纯卦生成全部 64 卦(本宫→一世...五世→游魂→归魂),生成时同时得卦宫与世爻(应爻 = 世±3)。非硬编码,可自证。
- **纳甲 / 六亲 / 六神 / 旬空 / 变卦**:查表 + 规则。六亲以卦宫五行为「我」按生克判;六神按日干起;旬空一条公式;变卦翻动爻重走定卦宫。

## 断卦(analysis.py)

- **取用神**:`CATEGORY_YONGSHEN` 把所测事映射到六亲;两现按 临世 > 发动 > 临日月 > 旺相 打分取一(逢空降权)。
- **用神不上卦 → 伏神飞神**:自本宫首卦(纯卦)同位取伏神,本卦同位为飞神,判飞伏生克与伏神旺衰,得「可出 / 难出」。
- **旺衰**:月建五等(旺相休囚死)。
- **生克演算**:动爻按对用神角色(原神 / 忌神 / 泄神 / 同类 / 受制)分类,先算自身强弱(月建 + 临日 + 日生克 + 月冲),再看变爻回头生 / 回头克 / 化进神 / 化退神;用神自发动单独判。
- **入墓 / 月建生扶**:用神入日墓、月建生合各出断语。
- **应期(启发式,置信低)**:空→出空(填实 / 冲空),动→逢合,静→逢冲 / 值日,入墓→冲墓,伏→值伏 / 冲飞。

## 引擎 ↔ LLM 契约(三条边界)

1. 引擎明确结论,LLM 不得推翻。
2. 引擎标「待 / 不确定」,LLM 用陪伴口吻给倾向 + 需观察,不硬断。
3. 敏感域(健康 / 生死 / 投资)由上层护栏拦截,转情绪陪伴。

## 输入依赖

`month`(节气月支)与 `day`(日辰干支)由历法层提供。参考 `lunar_python`:
`Solar.fromYmd(y,m,d).getLunar()` 的 `getMonthInGanZhiExact()` 与 `getDayInGanZhiExact()`。

## 定位与免责

定位「情绪陪伴 / 自我探索」的结构化辅助,非预测事实;应期为启发式;断语均带置信与不确定度,如实标注。健康 / 投资 / 寿命等由上层安全护栏处理。
